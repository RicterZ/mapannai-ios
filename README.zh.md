# MapAnNai iOS（マップ案内）

[English](README.md) | 中文 · [MapAnNai Plus](https://github.com/RicterZ/mapannai-plus) · [下载 IPA](https://github.com/RicterZ/mapannai-ios/releases/latest)

把想去的地方放到地图上，再把每天的旅行计划带在身边。

MapAnNai iOS 是 MapAnNai Plus 的原生 iPhone 和 iPad 客户端。你可以收藏餐厅、酒店和景点，记录照片与笔记，按旅行和日期安排访问顺序。客户端与网页使用同一服务端的地点和旅行数据，在电脑上做好的计划，可以在手机上继续查看和编辑。

启动显示页内大标题“我的旅途”的卡片首页，可下拉刷新旅途与地点。进行中的旅途优先置顶，全部完整展示且彼此留有间距，右上角以素绿圆点标注“旅途中”；没有进行中的旅途时，最近将出发的旅途完整展示在顶部，其余旅途在下方从新到旧层叠排列，并将同尺寸的年份卡片堆叠其中，按出发年份分组。没有进行中或未来旅途时，顶部展示出发日期离今天最近的旅途。每年自动生成不同的固定配色和图案，不会在刷新或重启时变化；年份卡片不可点击。点卡进入整页旅行详情，查看每天安排，也可切换到地图视角；关闭旅行详情回到原来的卡片位置。每天以连续篇章呈现日序、日期、可选主题、横幅地点照片与图注、地点顺序和已有时间安排；路线以节点与细线预览，未编排地点单独弱化显示，不混入路线正文；无主题或未使用照片时直接省略，不添加占位；同一旅行内封面及前面日期已使用的图片不重复显示。点击日期右侧的省略号，可编辑主题和当天地点。添加一天使用相同编辑页，主题可留空，地点仅从本次旅途中选择，也可不选；提交后立即更新界面并后台保存，失败可继续编辑；旅途卡片以淡化照片作背景，保持文字清晰；右下角按出发日期正序自动显示 No. 001 格式的编号。下方收纳旅途使用轻透视，点击后放平进入现有详情页；顶部完整展示的旅途保持正面，特殊年份卡仍保留在堆叠中。设置以轻量文字入口放在首页卡片列表底部，右下角悬浮加号用于创建旅行。还没有旅途时，首页显示三张同尺寸的首程档案卡与“创建旅途”按钮，不显示重复悬浮加号；点击即可开始创建。

首页卡片下方提供“聊聊下一程”：输入想法开始新对话，或通过会话记录和最近会话直接续聊。未配置 AI 时，发送会先打开聊天页并提示配置，输入保留；在设置中填写 AI API 和模型后可继续发送。聊天以整屏幕打开，助手回复采用正文阅读样式，工具过程可折叠；向上阅读历史时暂停自动跟随，会话列表支持切换和新建。点击返回箭头或从左边缘右滑只返回应用，不停止回复；可重新进入正在回复的会话查看进度。切到应用外的执行时间受 iOS 后台限制。

尚未加入旅途的地点显示在首页 AI 对话上方的“收藏地点”横向卡片中，有预览图时展示图片，无图时展示分类图标；点击卡片查看地点详情。

从首页打开旅行时，若包含设备本地日期对应的行程日，会定位到今日章节（空日也支持）；没有今日行程则保持原有打开位置。刷新、后台返回和子页面返回不会重复定位。

## 产品功能

- **收藏地点与旅行笔记**：搜索同时匹配已收藏地点的标题与地图兴趣点，已收藏地点优先显示，并带有原地点图标与“已收藏”标识，可直接复用到行程。也可点击地图上的兴趣点或长按地图添加地点，记下攻略、预订信息与旅行见闻。 添加地点先显示地图中心30公里内的已保存地点；搜索、结果和地点预览复用同一面板，下拉保留输入框，点击返回才退出，点选标记仅预览，明确加入才修改行程。旅行图标使用与Web一致的手绘SVG。半屏／全屏天详情中点击地点打开详情，关闭恢复原档位；可从详情移出今日行程并保留收藏及其他日期，也可彻底删除地点。地点编辑显示地址，位置通过地图选点维护。 地点详情在所属行程行显示第N天与完整日期，当前选中的目标日在行程名称后以灰色“（当前行程）”标记；未加入时按钮明确显示目标日序与日期，无目标日不显示加入操作。
- **按天安排行程**：创建旅行，先把地点收藏到“未安排日期”，再长按拖入某一天；当天无路线时首次添加建立路线1，只有一条路线时追加其中，多条路线时放入“未安排”。把地点加入每天的安排；编辑旅途复用创建页的名称、图标和日期范围控件，可整体改期或延长，保留已有每天的安排；单独删除日期仍在行程中操作，复用已经收藏的地点。删除旅行或某一天时，可选择同时清理独占地点，共享地点保留。
- **自由组织访问顺序**：一个地点即可创建路线，一天可以有多条路线，调整地点顺序，分别安排不同活动。通过日详情的“编辑模式”按钮或路线操作菜单进入选择与排序，通过选择栏移动、复制到另一天或从当天删除；地点与路线均不提供横滑操作，路线删除使用标题旁的操作菜单。编辑模式打开全屏工作区，复用现有地点和交通图标；点击时间安排或交通块编辑游览时间、交通方式、车次、出发时间、时长与备注。浏览时安排只读，编辑中的规划距离异步更新，不支持的路段不显示距离。同路线排序保留游览时间；交通起终点恢复原方向相邻时，原安排会重新显示。
- **在地图上横向浏览一天**：点击日期进入全屏日详情，顶部仍露出地图，也可下拉至半屏。正文支持跟手左右滑动切换相邻日期，选择与排序期间暂停切天。地点使用分类图标、最多两行的名称、单行地址，使用“编辑模式”按钮进入选择与排序，地点整行不提供长按编辑；右侧主次显示到达时间和停留时长；下方展示照片与可展开备注。交通使用中性浅灰块，保留方式、车次、出发时间、计划时长和可展开备注，在全屏行程编辑中修改。最小档为无照片的浅灰细边框地点卡，名称、地址、交通信息均单行，过长尾部省略；箭头上下显示交通信息，右侧露出下一站提示横滑，末站占满可用宽度并取消渐隐。横滑时黑色编号标记跟随焦点；手动缩放或拖动地图后不再自动定位。保留日期切换、定位与搜索。
- **在地图上看清整体安排**：查看全部地点、某次旅行或当天路线，用颜色区分日期，点击已保存地点打开白色贴边半屏详情，上拉展开、下拉恢复之前行程，点击连线查看对应行程。进入当天后，相邻地点间的静态小箭头沿路线等距排列，表示前往方向；系统地图、高德和 Google 使用一致的动画。
- **查看路线与打开导航**：根据每段交通安排由服务端规划路线，未安排时由服务端选择，无法规划时显示虚线曲线，出发时可以从地点打开系统地图或高德地图导航，在设置的“导航地图”中选择。 保存官方 POI 时会保留可获取的平台身份，系统地图和 Google 地图优先打开对应地点；没有身份的地点仍按坐标打开。
- **在手机和平板上使用**：iPhone 上收起胶囊可切换旅行日期，iOS 26 及以上采用液体玻璃，较早系统使用毛玻璃，拉起查看行程，iPad 上地图与行程并排显示，方便比较地点、整理安排。
- **与网页共用旅行数据**：连接自己的 MapAnNai Plus 服务，在 Web、iPhone 和 iPad 上继续编辑同一份旅行。


## 开始规划

1. 在应用设置中连接自己的 MapAnNai Plus 服务。
2. 搜索、点击地图上的兴趣点或长按地图添加想去的地方，记录笔记与照片。
3. 点击“我的旅途”或收起面板的＋，在“新的旅途”中先搜索并选择一个或多个目的地省市，空名称框会滚动展示随机地名与主题组合，仅作提示，不会自动填写。再填写名称、从图标面板选择旅行图标、直接选择出发和结束日期范围，再点“创建旅途”。把地点加入每天的安排，再调整路线中的访问顺序。
4. 出行时打开当天行程，查看地点、阅读攻略或打开导航。

还没有服务端？按照 [MapAnNai Plus 的部署说明](https://github.com/RicterZ/mapannai-plus/blob/main/README.zh.md#部署自己的服务) 准备服务，再在客户端填写服务地址及服务需要的 API token。搜索、保存和路线规划需要网络连接。

默认底图为系统地图（Apple MapKit）。在设置 → 地图与路线 → 地图底图中可选择系统地图、高德或 Google 地图。未配置 Google SDK Key 时静默使用系统地图。底图切换不改变所连服务器的搜索与寻路服务。

点击每日行程中的路线标题可在地图查看整条路线，右侧箭头独立展开或收起地点列表。
开启路线规划后，相邻地点之间会显示该段已规划路径的距离。地图连线会简化小绕圈和短折返，以突出访问顺序；距离仍使用原始规划结果。来回共线路段会轻微错开，在街区尺度下更容易区分。

启动地图优先显示按日期选择的行程；没有可定位的行程时，允许定位可查看当前位置。搜索从底部弹出，可上拉展开，点击结果后在地图显示该地点的名称标签，并打开半屏地点详情。

## 安装到 iPhone / iPad

需要 **iOS / iPadOS 17 或更新版本**。Release 提供未签名的 `.ipa`，可通过 **AltStore Classic** 签名安装。

1. 按照 [AltStore 官方指南](https://faq.altstore.io/altstore-classic/how-to-install-altstore) 在电脑安装 AltServer，再为 iPhone 或 iPad 安装 AltStore Classic。根据系统提示开启开发者模式。
2. 在设备上打开 [Releases](https://github.com/RicterZ/mapannai-ios/releases/latest)，下载 `MapAnNai-0.0.1-unsigned.ipa`，存到“文件”。
3. 打开 AltStore Classic → **My Apps** → 左上角 **＋**，选择下载的 IPA，按提示完成签名和安装。按 AltStore 要求保持与 AltServer 的连接。
4. 使用免费 Apple 账号安装的应用通常需要每 **7 天续签**，在 AltStore 中刷新应用即可。连接和自动刷新方式见 [AltStore 使用指南](https://faq.altstore.io/altstore-classic/your-altstore)。

这里使用的是 **AltStore Classic**，不是 AltStore PAL。重签可能改变应用 Bundle ID，而高德地图 Key 绑定 Bundle ID；如果安装后地图鉴权失败，需要使用与签名后 Bundle ID 匹配的 Key 重新构建，详见 [构建指南](docs/development.md)。不能保证任意账号重签后地图均可用。
