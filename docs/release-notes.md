MapAnNai iOS 首个公开版本，支持 iOS / iPadOS 17 及以上版本。

- 在地图上搜索、收藏地点，添加照片和旅行笔记。
- 按旅行和日期整理行程，查看路线并打开 Apple Maps 导航。
- iPhone 随身查看，iPad 地图与行程并排规划。
- 连接 MapAnNai Plus，与 Web 端共用数据。

下载 `MapAnNai-0.0.1-unsigned.ipa`，通过 AltStore Classic 签名安装。

[安装与使用说明](https://github.com/RicterZ/mapannai-ios#安装到-iphone--ipad) · [MapAnNai Plus](https://github.com/RicterZ/mapannai-plus)

此包未签名，不包含开发者证书或设备描述文件。免费 Apple 账号通常需要每7天续签。AltStore 重签可能改变 Bundle ID；高德地图 Key 与 Bundle ID 不匹配时需要重新构建，不能保证任意账号重签后的地图鉴权。

附件 `.sha256` 用于校验 IPA 完整性。本发布不代表已完成 AltStore 真机安装验证。
