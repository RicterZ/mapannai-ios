# 旅行专属地点笔记

需要支持旅行笔记接口的 MapAnNai Plus 服务。旧服务可继续读取原有行程；笔记接口返回404时提示升级或对象缺失，不将旅行正文写回通用攻略。

例如，同一个幕张展览馆可分别用于 FF14 和 BA 旅行，各自保留活动标题及正文，而场馆通用攻略只编辑一份。

## 保存本次笔记

Trip 的 markerNotes 缺省时读取为无笔记，随服务器/凭据摘要隔离的快照保存。地点身份、坐标、分类、封面和通用攻略共享；旅行活动标题和富文本正文按 (tripId, markerId) 独立，访问安排仍按 stopId 保存。

编辑器冻结连接、旅行、地点及原始 updatedAt，使用 GET/PATCH/POST /api/trips/:tripId/markers/:markerId/note。PATCH 发送 title/content/expectedUpdatedAt，首次版本为 null；清空标题正文删除笔记。POST 仅发送版本，复制通用攻略到空正文，不清空源或覆盖标题。失败保留草稿，不自动重放。404 提示升级或对象缺失，409 必须刷新并核对版本。连接切换禁止旧编辑器提交。新建地点正文归属冻结目标旅行，部分成功重试复用真实地点 ID 和已确认笔记版本。

## 找回和删除

旅行详情「地点笔记」列出成员、路线及仅保留笔记的地点，可重新加入日期。删除单日保留旅行笔记；整旅删除候选包含仅笔记引用地点，其他旅行/日期和保留笔记保护共享地点；全局删除清除全部引用。数量和总览归属计入笔记。分享/导览展示本次标题及真实名称，目前不展示地点富文本，也不将 dataset 当作旅行笔记导出接口。

## 验证

验证用 URLProtocol 和只读示例，不操作生产数据。真实设备安装参照本机 docs/local/remote-device-installation.md；该本机文件不提交。
