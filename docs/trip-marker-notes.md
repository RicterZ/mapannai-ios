# 旅行专属地点笔记

需要支持旅行笔记接口的 MapAnNai Plus 服务。旧服务可继续读取原有行程；笔记接口返回404时提示升级或对象缺失，不将旅行正文写回通用攻略。旧服务上，在旅行内新建带正文的地点可能已创建地点但无法保存旅行正文；草稿和真实地点ID会保留，需升级服务后重试，不会自动降级或重复建点。

例如，同一个幕张展览馆可分别用于 FF14 和 BA 旅行，各自保留活动标题及正文，而场馆通用攻略只编辑一份。

## 保存本次笔记

Trip 的 markerNotes 缺省时读取为无笔记，随服务器/凭据摘要隔离的快照保存。地点身份、坐标、分类、通用封面和通用攻略共享；旅行活动标题、独立封面和富文本正文按 (tripId, markerId) 独立，访问安排仍按 stopId 保存。

详情显示全部所属行程，区分有日期、未分配日期与只保留旅行笔记，并高亮本地选择的旅行。优先选择实际所属的当前旅行，否则按开始日期选择最近未结束旅行，再回退到最近历史旅行。点击所属旅行只切换笔记和图片，再次点击保持选中；不会关闭详情、切换地图行程/日期或改变镜头。各旅行封面显示在对应所属行程行右侧，占行宽46%，未选中时透明度60%；有旅行归属时不显示独立大封面。详情打开期间切换当前旅行会重新选择对应笔记作用域。

详情先显示“行程笔记”标题、旅行图标名称标签、活动标题与有效正文；标题和正文皆空时显示添加提示。通用笔记始终在所选行程笔记下方，默认折叠，收起显示共享封面缩略图与单行纯文本摘要，展开显示共享封面与富文本；切换地点恢复折叠，切换旅行不重置。无通用封面或有效正文时显示空状态。无旅行归属时直接显示通用封面及正文。空段落、空白实体、注释和style/script/head/title/template/noscript不算正文，图片独立算有效内容。

顶部唯一编辑入口打开同一个原生sheet，选择通用资料或该地点实际所属旅行。跟随详情所选作用域，无旅行归属时初始通用；不会因为当前选择了其他旅行就隐式创建归属。各作用域保留独立标题/正文/封面草稿及首次打开时版本；保存仅写当前范围，其他草稿仍保留在sheet中。

编辑器冻结连接、旅行、地点及原始 updatedAt，使用 GET/PATCH/POST /api/trips/:tripId/markers/:markerId/note。PATCH 发送 title/content/expectedUpdatedAt，首次版本为 null；封面未修改时省略headerImage保留未知服务器字段，修改时发送HTTP(S) URL（最多4096字），移除发送null，空字符串同样清除。标题、正文、封面全空才删除；仅封面笔记仍保留归属和删除保护。POST 仅发送版本，复制通用攻略到空正文，不清空源或覆盖标题。失败保留草稿，不自动重放。404 提示升级或对象缺失，409 必须刷新并核对版本。连接切换禁止旧编辑器提交。新建地点正文归属冻结目标旅行，部分成功重试复用真实地点 ID 和已确认笔记版本。

## 图片显示

旅行内只用该旅行独立封面，缺少时取该旅行正文第一张HTTP(S)图片，无图不借用其他旅行或通用图。详情的通用笔记只读取通用封面/通用正文首图，不从旅行借图；无归属地点详情也只显示通用图。总览地点缩略图按旅行startDate倒序、updatedAt倒序、ID升序查找有图旅行，全部无图才回退通用图。旅途章节照片和分享照片保持现有PlaceImage规则；通用资料编辑仍只显示并编辑全局原字段。旧响应缺少headerImage可读取，不会因为未编辑封面而清空服务器现有图。历史正文不自动搬迁。

## 找回和删除

旅行详情「地点笔记」列出成员、路线及仅保留笔记的地点，选中目标日期后可使用原有“加入今日行程”操作。删除单日保留旅行笔记；整旅删除候选包含仅笔记引用地点，其他旅行/日期和保留笔记保护共享地点；全局删除清除全部引用。数量和总览归属计入笔记。分享/导览展示本次标题及真实名称，目前不展示地点富文本，也不将 dataset 当作旅行笔记导出接口。
