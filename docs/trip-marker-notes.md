# 旅行专属地点笔记

需要支持旅行笔记接口的 MapAnNai Plus 服务。旧服务可继续读取原有行程；笔记接口返回404时提示升级或对象缺失，不将旅行正文写回通用攻略。旧服务上，在旅行内新建带正文的地点可能已创建地点但无法保存旅行正文；草稿和真实地点ID会保留，需升级服务后重试，不会自动降级或重复建点。

例如，同一个幕张展览馆可分别用于 FF14 和 BA 旅行，各自保留活动标题及正文，而场馆通用攻略只编辑一份。

## 保存本次笔记

Trip 的 markerNotes 缺省时读取为无笔记，随服务器/凭据摘要隔离的快照保存。地点身份、坐标、分类、封面和通用攻略共享；旅行活动标题和富文本正文按 (tripId, markerId) 独立，访问安排仍按 stopId 保存。

详情显示全部所属行程，区分有日期、未分配日期与只保留旅行笔记，并高亮当前旅行。旅行正文完整平铺在通用笔记之前，不使用折叠或分散编辑入口。点击所属旅行进入对应旅途且保持地图镜头。

顶部唯一编辑入口打开同一个原生sheet，选择通用资料或该地点实际所属旅行。旅途外默认通用，旅途内仅在真实所属时默认当前旅行；不会因为当前选择了其他旅行就隐式创建归属。各作用域保留独立草稿及首次打开时版本；保存仅写当前范围，其他草稿仍保留在sheet中。

编辑器冻结连接、旅行、地点及原始 updatedAt，使用 GET/PATCH/POST /api/trips/:tripId/markers/:markerId/note。PATCH 发送 title/content/expectedUpdatedAt，首次版本为 null；清空标题正文删除笔记。POST 仅发送版本，复制通用攻略到空正文，不清空源或覆盖标题。失败保留草稿，不自动重放。404 提示升级或对象缺失，409 必须刷新并核对版本。连接切换禁止旧编辑器提交。新建地点正文归属冻结目标旅行，部分成功重试复用真实地点 ID 和已确认笔记版本。

## 找回和删除

旅行详情「地点笔记」列出成员、路线及仅保留笔记的地点，选中目标日期后可使用原有“加入今日行程”操作。删除单日保留旅行笔记；整旅删除候选包含仅笔记引用地点，其他旅行/日期和保留笔记保护共享地点；全局删除清除全部引用。数量和总览归属计入笔记。分享/导览展示本次标题及真实名称，目前不展示地点富文本，也不将 dataset 当作旅行笔记导出接口。
